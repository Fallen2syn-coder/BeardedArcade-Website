Privacy Policy

Effective 2026-09-20

TBA Clip Poster ("the tool") is a private, single-user application used by The Bearded Arcade (Fallen2syn) to publish the operator's own gameplay clips to the operator's own TikTok account.

What data is accessed

Through TikTok Login Kit and the Content Posting API the tool accesses only the operator's own account: basic profile information (display name, avatar) and the ability to upload and publish videos on the operator's behalf.

What data is stored

OAuth credentials for the operator's own account are stored locally on the operator's computer. No data about any other TikTok user is collected, stored, or processed.

Sharing

No data is sold or shared with third parties. Data goes only between the operator's computer and TikTok's API.

Retention and deletion

Credentials are kept until the operator revokes them (TikTok → Settings → Security → Manage app permissions) or deletes the local files, at which point the tool retains nothing.
